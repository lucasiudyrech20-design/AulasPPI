O que é JavaScript?

JavaScript é uma linguagem de programação criada para tornar as páginas da internet mais dinâmicas e interativas. Inicialmente, foi desenvolvida para permitir interações com os usuários, como validar formulários e responder a cliques em botões.

No navegador, o JavaScript é executado no computador do usuário, permitindo manipular elementos HTML e CSS. No servidor, pode ser executado com ambientes como Node.js, permitindo criar sistemas, APIs e acessar bancos de dados.

O sandbox é um ambiente de segurança do navegador que limita o acesso do JavaScript ao computador do usuário, protegendo arquivos e informações pessoais.

Alguns objetos globais do JavaScript são:

  • document, utilizado para manipular elementos da página;
  • console, utilizado para registrar mensagens e informações;
  • alert, utilizado para exibir mensagens em janelas de alerta.
