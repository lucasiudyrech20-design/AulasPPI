Arquitetura Cliente servidor da WEB

As tecnologias que fundamentais que compoem a WEB são:

  • Arquitetura Cliente Servidor
  • HTTP - Hyper Text Tranfer Protocol
  • HTML - Hyper Text Markup Language
  • Navegador Cliente -
  • Servidor Web

Ao longo dos anos a web evoluiu e novas tecnologia foram introduzidas como CSS e JavaScript
