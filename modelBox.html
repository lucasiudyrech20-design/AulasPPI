Modelo em Caixa, Model Box HTML

Os elementos html são estruturas em um modelo denominado modelbox, que refere-se a caracteristica de um elemento pode conter outros elementos, sendo que cada um possui uma estrutura interna, similar a idei de uma caixa dentro da outra.

Estrutura de um elemento HTML

Todos os elementos HTML possuem conteúdo, padding, borda, offset. Sendo a região de conteúdo estruturada em três camadas 1)background-color 2)background-image 3)Content
